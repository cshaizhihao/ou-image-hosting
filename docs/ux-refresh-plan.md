# 体验改版与本地预览

## 设计范围

使用已安装的 frontend-design、web-design-guidelines、vercel-react-best-practices 和 playwright。
更新图片管理体验、媒体管线、存储说明与发布部署。正式上线使用独立子域名和 Cloudflare 代理；在已有服务的服务器上采用独立项目与数据目录。

视觉规则：纸白 #F7F8FA、纯白 #FFFFFF、墨色 #20252C、珊瑚 #E7777F、细边框 #E5E7EB、成功绿 #217A56；深色使用对应语义变量。
猫头与品牌字保留在 Logo；工具页使用清晰的系统无衬线字体。标题 28px，正文 14–16px，操作区左对齐。
布局收紧侧栏与顶部高度，图片库把更多空间留给图片；上传入口紧凑，任务结果直接可操作。

```text
侧栏 | 搜索内容                          上传 / 账号
     | 图片库                     上传图片
     | 搜索 / 格式 / 排序         视图 / 大小
     | 缩略图   缩略图   缩略图   缩略图
     |               快速预览：图片 + 复制/详情
```

验收：真实点击操作、键盘与焦点、375/768/1024/1440 视口、浅色/深色、失败状态及原有功能回归。

## 本地临时资源

- `.data/local-preview/`：仅供预览的账号和图片；不连接 VPS 或云存储。
- `apps/web/.next-preview/`：预览独立编译缓存。
- `output/playwright/`、`output/review/`：截图和测试产物。
- `node_modules/`、其他 `.next/` 与 `dist/`：可重新生成的开发依赖和构建产物。
- 项目上一级 `.local-tools/`：本机专用 npm/npx 等工具与缓存。
- `/private/tmp/ou-image-review-*`：上一轮检查使用的临时工具、缓存与日志。

这些文件均不应进入 Git。**整个项目更新完成后，必须提醒用户停止本地预览并按清单清理临时资源。**
不要在仍需对比效果时清除预览图片；不要删除用户原始凭据、源码、Git 历史或需要保留的审阅文档。
