# v1.1.0 — 图片管理体验更新

图片库、上传与相册改为更紧凑的工作台布局，手机上也能完成选择、预览和整理。

- 图片卡片支持快速预览、左右切换和复制链接。批量复制可选择 URL、Markdown、HTML 或 BBCode；从详情返回时保留筛选和分页。
- 全局搜索可找到图片、相册和标签。相册选图支持全库搜索与分页，封面也可翻页选择。
- 上传队列在站内切换页面后继续运行，并显示返回队列的入口。刷新或关闭标签页仍会中断未完成任务；退出账号会清空队列。
- 完善 HEIC/HEIF 选择、错误反馈、超时与暂停/重试；上传成功但归档失败时保留图片结果并说明失败的设置。
- Live Photo 按同名图片与视频配对，补齐动态片段校验、播放与 Range 请求、配额统计、配置保存和关联清理。
- 修复签名直链的版本参数、停用账号后遗留 API Token、并发上传超额与共享原文件删除竞争问题。
- 未配置邮件服务时，找回密码页提供真实的恢复说明；新增[管理员离线恢复工具](../account-recovery.md)。
- 更新依赖及 Node 运行环境，分离本机预览、浏览器测试与生产构建缓存，完善测试进程清理。

## 部署与数据

继续使用单个 API 进程、JSON 元数据和本地数据卷。S3/R2 目前用于配置、连通测试与迁移复制，不能切换成日常读写源。应用内备份最多容纳 128 MiB 文件、64 MiB 压缩归档；大图库应使用数据卷快照。

升级前按[备份指南](../backup-restore.md)保留数据卷快照，并保留原 `OU_SECRET_KEY`。当前状态模式为 v8，已有 v8 数据无需手工迁移。

## 本机预览

安装 Node.js 24 和 pnpm 9.15.9 后：

```bash
pnpm install --frozen-lockfile
pnpm preview:local
```

预览只监听本机 `127.0.0.1:3280`，使用独立测试账号与数据，不连接生产服务器。停止命令为 `pnpm preview:stop`。全部更新完成后，按[临时资源清单](../ux-refresh-plan.md#本地临时资源)清理缓存和测试图片，保留源码及生产凭据。
