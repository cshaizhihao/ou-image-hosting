# OU-Image Hosting V2.0.1

建议使用 V2.0.0 或更早版本的站点升级。升级保留现有数据结构、图片和直链。 [升级指南](../upgrading.md)

- 隔离匿名上传的图片记录，避免同图去重返回其他人的图片直链或改变其公开状态。公共图库会将匿名投稿标为「匿名访客」。
- 首页上传和后台上传统一校验工作区写权限及令牌范围。NodeSeek 专用凭据继续通过绑定分组的接口上传。
- 分享密码验证前，公开接口隐藏可推导直链的图片 ID。签名和防盗链保护的图片响应禁止缓存。
- S3 兼容端点保留配置的路径前缀，远程图片读取增加总超时。
- 首页快速连续粘贴时，只发起一次上传。
- `ouih update` 等待容器就绪后才记录更新成功。
