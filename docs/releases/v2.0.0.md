# OU-Image Hosting V2.0.0

V2.0.0 汇总了欧记图床从首个正式版本以来的体验更新，重点是上传首页、对象存储和 NodeSeek 发图。

- 首页改成直接上传的工作区。选择文件、拖放或粘贴后可复制链接，登录用户可以就地管理上传历史。
- 本地存储、Amazon S3 和 Cloudflare R2 可以切换为当前存储。切换前进行连接、读取、写入和删除校验，已有图片继续从原位置读取。
- NodeSeek 脚本支持粘贴截图、选择文件或从论坛图片菜单发起上传。凭据绑定分组，可由管理员撤销。脚本版本为 1.1.1。
- 使用新版猫咪 Logo，并更新 README 的功能说明、部署入口和演示截图。

从已安装的版本升级前，先导出备份并保留当前配置、存储凭据和 `OU_SECRET_KEY`。升级后可通过 `ouih status` 查看服务状态。 [升级指南](../upgrading.md) · [备份与恢复](../backup-restore.md)
